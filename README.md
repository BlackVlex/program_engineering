# Римско-Бразильская война: Стратегический экшен от 2-го лица

**Репозиторий проекта:** [https://github.com/BlackVlex/program_engineering](https://github.com/BlackVlex/program_engineering)  
**Площадка:** GitHub (выбрана из-за удобной системы Pull Requests, Issues и интеграции с VS Code).

## Назначение продукта
Коммерческий развлекательный продукт (компьютерная игра) — стратегический экшен от 2-го лица в альтернативно-историческом сеттинге «Римско-Бразильская война в Японии». 
Целевая аудитория: мужчины 18–32 лет, интересующиеся стратегиями и альтернативной историей.

## Краткий перечень возможностей
- Управление офицером бразильской армии от 2-го лица.
- Тактические сражения с римской армией на территории Японии.
- Экономическая механика: торговля ресурсами и грабёж караванов.
- Стратегическое развитие: строительство зданий и разбивка лагерей в захваченных провинциях.
- Кроссплатформенность: Windows, macOS, Linux (движок Unity).
