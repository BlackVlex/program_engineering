### Вариант использования 3. «Использование карты»
**Разработчик:** Игнатушин Владимир.
**Согласовано с:** Храмов Д.Э.

**Описание:**
Игрок открывает карту для просмотра местности, навигации, разведки и стратегического планирования. Карта ограничена территорией Японии.

**Действующие лица:**
Игрок (офицер бразильской армии), Система.

**Предусловия:**
Игрок находится в игре, карта доступна для открытия.

**Основной поток:**
1. Игрок открывает карту.
2. Система отображает территорию Японии с отметками.
3. Игрок просматривает местность и навигацию.
4. Игрок видит отметки войск, лагерей, рынков и ресурсов.
5. Игрок запрашивает разведданные о противнике.
6. Система отображает данные разведки.
7. Игрок планирует атаку, оборону или торговлю.

**Альтернативные потоки:**
А1. Нет разведданных о противнике — система показывает сообщение «данные отсутствуют», игрок отправляет разведку.
А2. Игрок пытается выйти за пределы Японии — система блокирует навигацию и показывает сообщение об ограничении.

**Постусловия:**
Карта закрыта или игрок перешёл к действию (атака/оборона/торговля). Состояние отмеченных объектов актуально.

### Вариант использования 6. «Разбивка нового лагеря при захвате провинции»
**Разработчик:** Игнатушин Владимир.
**Согласовано с:** Храмов Д.Э.

**Описание:**
При захвате новой провинции игрок получает возможность разбить там новый лагерь как опорный пункт для дальнейших действий.

**Действующие лица:**
Игрок, Система.

**Предусловия:**
Провинция захвачена игроком. У игрока есть ресурсы для разбивки лагеря (если это требуется по балансу).

**Основной поток:**
1. Система фиксирует захват провинции.
2. Система предлагает разбить новый лагерь.
3. Игрок подтверждает размещение лагеря.
4. Система проверяет доступность места и ресурсов.
5. Система размещает лагерь и отмечает его на карте.
6. Система обновляет прогрессию: провинция становится опорным пунктом.

**Альтернативные потоки:**
А1. Недостаточно ресурсов — система сообщает об этом, игрок откладывает разбивку.
А2. Игрок отказывается от лагеря — провинция остаётся без опорного пункта.

**Постусловия:**
Лагерь разбит, провинция закреплена за игроком, карта обновлена.
